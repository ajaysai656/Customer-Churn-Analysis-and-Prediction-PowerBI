 📊 Customer Churn Analysis & Prediction - Power BI

## 📌 Project Overview
This project analyzes customer churn behavior using Power BI and identifies key drivers influencing customer attrition.  
The dashboard provides insights into demographics, service usage, billing behavior, and churn prediction factors.

---

## 🎯 Business Objective
To identify high-risk customer segments and understand factors contributing to churn in order to improve retention strategies.

---

## 📂 Dataset Information
- Total Customers: ~7,000
- Churn Rate: 27%
- Data Type: Telco Customer Dataset
- Features: Demographics, Services, Contract, Billing, Tenure

## 🔎 Key Insights
- Month-to-month contract customers have the highest churn rate.
- Fiber optic users show significantly higher churn compared to DSL.
- Electronic check payment method is strongly associated with churn.
- Customers with low tenure (0–6 months) are at highest churn risk.
- Lack of tech support and online security increases churn probability.
